# ATS 课题一 Skills

本仓库包含自主式交通系统（ATS）计算技术课题一算法模型相关的 Skills。仓库结构参考 [jexxl/ats-skills](https://github.com/jexxl/ats-skills)，具体流程、模板和校验规则面向课题一单独维护。

## 包含的 Skill

- `ats-kt1-algorithm-docs`：盘点课题一 Docker 算法包，记录真实输入输出，并按参考模板生成和校验“测试说明”与“模型原理说明” Word 文档；提供最新命名 Excel 时核对“模型名称（现）”，未提供时从算法文件夹内已有文档读取模型名称。

## 使用输入

使用本 Skill 时必须有以下两类参考文档，可以使用项目提供的最新版，也可以使用仓库内置示例：

- 测试说明参考模板或示例：`skills/ats-kt1-algorithm-docs/assets/测试说明-示例.docx`
- 模型原理说明参考模板或示例：`skills/ats-kt1-algorithm-docs/assets/模型原理说明-示例.docx`

最新命名 Excel 是可选项。如果提供，Skill 会检索“模型名称（现）”并按算法编号核对；如果没有，则从每个 `algo1-4-j-N` 算法文件夹内已有的测试说明或模型原理说明读取“模型名称”。项目现场提供的模板优先于仓库内置示例。若 Excel 和内部文档都不能提供模型名称，Skill 会停止并提示补充，不用文件夹编号冒充模型名称。

仓库同时内置 `skills/ats-kt1-algorithm-docs/references/算法提交说明.md`。Docker 运行失败、镜像需要修复或算法提交目录需要整理时，按该规范检查镜像命名、目录布局、输入输出挂载、`params.json` 和 `test_options/`。

## 整体运行流程

### 0. 确定算法名称

先检查是否提供“算法编号—新算法名”的最新命名 Excel 映射表：

- 如果提供映射表，按算法编号查询“模型名称（现）”，再与算法文件夹内已有测试说明或模型原理说明中的名称比较。两者不同时判定为需要改名，后续新生成的测试说明和模型原理说明必须全部使用映射表中的最新名称，包括基本信息、模型介绍、图表文字、测试结果和测试通过条件，不混用旧名称。
- 如果映射名称与内部文档名称相同，判定为不需要改名，沿用内部文档中的名称。
- 如果没有提供映射表，从算法文件夹内已有测试说明或模型原理说明的“模型名称”字段取名。内部文档也无法提供名称时停止生成并请求补充，不使用算法文件夹编号代替名称。

### 1. 运行 Docker 并同步填写测试说明

先读取算法文件夹内已有的旧测试说明和模型原理说明，将其中的算法功能、输入输出含义、文件名称、字段含义、指标名称、指标单位、已有指标数值及性能结论作为内容基线，不随意改名、删减或替换。随后实际加载和运行 Docker，并在运行、检查输入和解析输出的过程中同步整理测试说明：

- 旧文档用于保持算法设计、输入输出语义、指标名称、指标口径、已有数值和性能结论一致。
- Docker 实际运行用于核实当前提交包的输入目录结构、具体文件格式、字段结构、运行参数、输出文件、命令行结果和可复现命令。
- 如果当前输出缺少旧文档中已有的指标，按同一算法的旧文档补充；不跨算法引用指标，不在新文档中记录补充来源。
- 如果 Docker 运行失败，先按照 `references/算法提交说明.md` 检查并修正镜像、目录、入口、挂载、`params.json` 和运行资源，使算法能够按规范正常运行；修正后重新加载算法文件夹内的最终镜像并完整复测，再完成测试说明。
- 测试说明使用确定后的统一算法名称和参考模板，写明已验证的 Docker 运行配置、运行命令、预期输出以及测试通过条件。

### 2. 填写模型原理说明

测试说明生成并校验后，再填写模型原理说明。算法设计、原理和模块细节以同一算法文件夹内已有模型原理说明为依据；模型输入输出直接参考已整理好的测试说明，确保文件名、格式、字段和指标完全一致。使用步骤 0 确定的统一算法名称和模型原理说明模板，补充完整的算法简介、框架图、流程图、关键模块及应用场景，最后校验 Word 可正常打开且版式符合模板。

两类文档全部完成后，统一检查算法名称、输入输出和指标的一致性，并清理本次生成的临时文件、渲染文件、Python 缓存、容器及本次加载的镜像标签；不删除任务开始前已经存在的 Docker 资产。

## 安装

推荐使用 `npx skills`：

```bash
npx skills add CheeryLeeyy/ats-kt1-skills --list
npx skills add CheeryLeeyy/ats-kt1-skills --skill ats-kt1-algorithm-docs
```

也可克隆本仓库，将 `skills/ats-kt1-algorithm-docs` 复制或链接到 Agent 的 skills 目录。

## 维护约定

- `main` 只保留通过校验的稳定版本。
- 模板、结构化数据规范或生成器变更使用独立分支和 Pull Request。
- 提交前运行 `python scripts/validate_repository.py`。
- 不提交算法镜像、业务数据、实测输出、已生成文档或服务器绝对路径。

## 运行环境

Word 生成和大部分校验脚本仅使用 Python 标准库。Docker 实测需要 Docker CLI，SVG 转 PNG 和 DOCX 视觉检查需要 LibreOffice。
